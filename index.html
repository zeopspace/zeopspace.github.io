🚀 What is WebKVM?

WebKVM is a powerful, self-hosted web application that gives you complete control over your Linux virtualization server from any web browser. Whether you're running KVM/QEMU virtual machines or Incus containers, WebKVM provides a clean, intuitive interface to manage all your virtualization needs without needing to remember complex command-line instructions.

Think of it as your personal control tower - you can start, stop, monitor, and configure your virtual machines and containers just by clicking buttons in your favorite web browser. No technical degree required!

✨ Key Features

🖥️ Virtual Machine Management

Create, start, stop, pause, and delete KVM/QEMU virtual machines with a simple click. No more memorizing complex commands!

📦 Incus Container Control

Manage your Incus containers effortlessly - deploy new ones, monitor resource usage, and scale as needed.

📊 Live Resource Monitoring

See real-time CPU, memory, disk, and network usage for all your virtual machines in a beautiful dashboard.

🔒 Secure Web Access

Access your virtualization host from anywhere securely, with built-in authentication and encrypted connections.

📸 ISO and Image Library

Upload and manage ISO files and container images directly through the web interface. Install new systems instantly!

👥 Multi-User Support

Invite team members and control their permissions. Collaborate on managing your virtualization infrastructure.
